METHOD 4: MANUAL COMPILATION (FOR CUSTOM PROGRAMS)
================================================================================

Step 1: Build the library
--------------------------
cd /Users/nyuad/Desktop/canim
make build/libcmanim.a

Step 2: Compile your program
-----------------------------
gcc -std=c23 -O3 -DGL_SILENCE_DEPRECATION -Iinclude -Isrc \
    your_program.c build/libcmanim.a \
    -L/opt/homebrew/lib -lglfw \
    -framework OpenGL -framework Cocoa -framework IOKit -framework CoreVideo \
    -lm -o your_program

Step 3: Run
-----------
./your_program

TYPICAL WORKFLOW
================================================================================

1. Run existing examples:
   make run-demo

2. View the source:
   cat examples/graph_demo.c

3. Modify it or create new file:
   cp examples/graph_demo.c my_animation.c
   # Edit my_animation.c

4. Compile your version:
   gcc -std=c23 -O3 -DGL_SILENCE_DEPRECATION -Iinclude -Isrc \
       my_animation.c build/libcmanim.a \
       -L/opt/homebrew/lib -lglfw \
       -framework OpenGL -framework Cocoa -framework IOKit -framework CoreVideo \
       -lm -o my_animation

5. Run it:
   ./my_animation

6. View output:
   open my_animation.mp4

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "make: command not found"
Solution: Install Xcode Command Line Tools
          xcode-select --install

Problem: "GLFW not found"
Solution: brew install glfw

Problem: "ffmpeg not found"
Solution: brew install ffmpeg

Problem: "No such file or directory: cmanim.h"
Solution: Use -Iinclude when compiling

Problem: Video is blank/white
Solution: Check function range and camera zoom
          Try: cm_scene_set_camera(scene, (CMCamera){0, 0, 1.0f});

================================================================================
COMMON COMPILATION FLAGS
================================================================================

Required:
  -std=c23                    Use C23 standard
  -Iinclude -Isrc             Include directories
  build/libcmanim.a           The library
  -L/opt/homebrew/lib -lglfw  GLFW library
  -framework OpenGL ...       macOS frameworks
  -lm                         Math library

Optional:
  -O3                         Optimization (faster)
  -DGL_SILENCE_DEPRECATION    Hide OpenGL warnings
  -g                          Debug symbols
  -Wall -Wextra               More warnings

================================================================================
PERFORMANCE
================================================================================

On Apple M1:
  - Rendering: ~140 FPS @ 1080p
  - Encoding: 2-3x realtime
  - 600 frames in ~4 seconds

To speed up:
  - Reduce FPS: 30 instead of 60
  - Reduce resolution: 1280x720
  - Reduce samples: 1024 instead of 4096
  - Shorter duration: 3s instead of 10s
